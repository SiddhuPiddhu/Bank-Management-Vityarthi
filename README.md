# Project Title-  VITyarthi Bank Management System




A simple CLI based banking project, simulated in Python. This project implements day-to-day banking operations such as- account creation, deposit/withdrawal, money transfer, and passbook/history checking.




## Overview of the project




This project was created to develop an understanding about how to handle file based data persistence and CLI state management in Python. Here we have stored all relevant information related to the users, transactions, and balances in a simple JSON file, instead of using any external database.




## Features




- Pin are hidden for security

- Automatically generate your ID after login in

- Simple system for checking deposits, withdrawals and the direct fund to another users

- Bank Statement / History Viewer

- Pin recovery system if you forget your pin based on secret question

- Auto save the informations into the database file




## Technologies/tools used




- Python & Standard Module

- JSON module for database




## Steps to install & run the project

- Ensure you have python installed

- Download the files as zip or clone the git directory 

- Run the main.py directly from the code editor or use python main.py inside the terminal





## Instructions for testing and How to use it




### Create an account

- Choose the 1st create account option

- Enter your full name

- Set a 4 digit PIN

- Select your security question and answer it

- Note the generated account id for login in




### Login

- Enter your account ID

- Enter your PIN

- Now you can access the banking dashboard




### Transaction actions

- Deposit: Add money to your bank balance

- Withdraw: Remove money from the bank if enough balance exists

- Transfer: Move funds to another user id

- History: View recent account history




### Forgot PIN

- Enter your account ID

- Answer the security question which you set while creating the account

- Set a new 4 digit pin
