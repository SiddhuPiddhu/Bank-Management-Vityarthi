# VITyarthi Bank Management System

## Problem Statement

Managing basic banking activities manually can be slow and difficult to track. VITyarthi provides a simple command line system where users can create an account, securely log in, and manage their money in one place.

## Scope of the Project

The project covers account registration, Pin based login and pin resetting, deposits and withdrawals, fund transfers, and transaction history. Account informations or history and transaction records are stored in a JSON file for persistent use.

## Target Users

The system is intended for students and individuals who need a simple way to practice or manage basic banking operations. It helps them to keep track of their money and use effectively for personal use.

## High-Level Features

- Create accounts with automatically and randomnly generated account IDs
- Log in using an account ID and pin
- Reset a forgotten PIN using a security question asked in the beginning
- Deposit and withdraw money
- Transfer funds to another account
- View recent transaction history
- Save account and transaction data between sessions

The system make basic banking tasks easier to understand and use.
